# Contributing

1. Create a focused branch from `main`.
2. Do not add customer data, private prices, production addresses or credentials.
3. Run `npm run verify:public-release` before committing.
4. Add tests for behavior changes.
5. Document new environment variables in `.env.example`.
6. Keep external sends auditable and fail closed when target identity is ambiguous.

By contributing, you agree that your contribution is licensed under Apache-2.0.
