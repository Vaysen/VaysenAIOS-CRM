# Vaysen AI CRM 使用指南

## 1. 首次登录

1. 管理员完成部署并运行数据库迁移。
2. 打开 Web 地址或 Windows 客户端。
3. 通过注册页创建第一个企业与管理员；生产环境应在创建后关闭公开注册。
4. 登录后先进入“系统设置”，配置企业名称、时区、默认币种和业务说明。

仓库没有通用默认密码，也不要把测试密码提交到 Git。

## 2. 客户资产

- 新增客户时优先填写公司名、联系人、邮箱、国家和完整国际电话号码。
- WhatsApp 电话号码应使用 E.164 格式，例如 `+12025550123`。
- 系统发现同一邮箱或号码属于另一客户时会提示冲突；请在查重/合并界面人工确认。
- 只有昵称而没有可信邮箱或号码时，可以保留会话，但不应自动生成“假完整档案”。

## 3. 产品与报价

1. 删除示例产品，导入企业审核后的产品与价格。
2. 打开客户详情或 WhatsApp 侧栏，选择“生成报价”。
3. 核对币种、贸易条款、交期、数量、单价、税费和备注。
4. 生成 PDF 后再次人工确认，再通过邮件或 WhatsApp 交付。

开源仓库中的价格为零，仅用于验证字段结构。

## 4. 邮件

1. 在“邮件账号”新增 SMTP 与 IMAP 配置。
2. 先执行连接测试，再发送到你控制的测试邮箱。
3. 配置每日/每小时限额、发送间隔和退订信息。
4. 收件依赖 IMAP 或入站 Webhook；只有 SMTP 时只能发件。

## 5. WhatsApp

- Electron 模式可以辅助使用 WhatsApp Web。
- 服务端自动化可配置 Evolution API；必须由部署者自行完成账号、Webhook 和平台合规设置。
- 第一次发送前确认当前会话、客户身份和目标号码一致。
- 若平台阻止自动附件发送，使用系统生成的 PDF 下载或拖拽交付作为人工兜底。

## 6. AI 业务助理

AI 助理工作台包含对话、事务、翻译/回复和汇报。一个有效请求应明确业务对象和目标，例如：

> 查询客户 `DEMO-001` 的最近沟通，生成英文跟进草稿并创建明天的待办。

涉及外发时，界面应显示目标、渠道、内容摘要和确认按钮。只有看到渠道返回的真实消息编号或工具成功回执，才算执行完成。

## 7. 订单与待办

- 报价确认后可以建立订单并记录金额、币种、交期和状态。
- 对客户承诺、样品、付款和交货事项建立明确负责人和截止时间。
- 首页和 AI 汇报读取的是 CRM 数据；若数据为空，先检查租户、权限和种子数据。

## 8. 备份

- 定期备份 PostgreSQL 与上传目录。
- WhatsApp/OpenClaw 会话数据与数据库备份分开加密保存。
- 至少每季度执行一次恢复演练。
- 不要只验证“备份文件存在”，必须验证可以恢复。

## 9. 常见问题

### AI 提示未启用

检查 `AI_EXTERNAL_CALLS_ENABLED`、对应供应商 API Key、Base URL、模型名和后端日志。前端显示的供应商名称必须与后端配置一致。

### 邮件能发不能收

确认账号配置了 IMAP，或配置了 Brevo 等入站 Webhook。SMTP 不提供收件能力。

### WhatsApp 客户无法自动建档

检查是否取得完整号码，是否与已有客户冲突，以及当前会话是否由受信来源返回。不要用联系人状态文字替代号码。

### AI 声称完成但系统没有变化

查看执行轨迹和工具回执。没有真实工具回执就不是完成。
